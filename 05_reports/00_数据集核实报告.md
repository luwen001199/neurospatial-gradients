# 数据集核实报告（执行正式分析前的强制前置步骤）

> 项目：TNBC 感觉神经驱动的空间免疫架构分型与 PNI 进展梯度研究
> 核实日期：2026-10-25
> 核实方式：NCBI GEO SOFT 元数据原文件 + NCBI E-utilities (`db=gds`) + cBioPortal REST API
> 结论：**方案中的 7 个数据集，2 个确认可用、2 个编号严重错误、2 个部分偏差、1 个不可达（需用户提供）、1 个非公开。**

## 一、逐数据集核实结果

### ❌ GSE256279 —— 方案声称「31 例 TNBC scRNA-seq」，实际完全不符

| 项目 | 方案描述 | GEO 官方元数据实名 |
| ---- | ---- | ---- |
| 标题 | 31 例 TNBC scRNA-seq | *Sirtuin 7 regulates dosage compensation and safeguards the female X-chromosome* |
| 物种 | 人 | **小鼠（mus/cas 杂交 TTF 细胞）** |
| 数据类型 | scRNA-seq | **ChIP-seq（H3K27me3）** |
| 样本量 | 31 | **8** |
| 平台 | — | GPL23479 |

> **判定：编号错误（张冠李戴）。该数据集与乳腺癌、单细胞、空间转录组毫无关系，必须先替换。**

### ❌ GSE240212 —— 方案声称「11 例乳腺癌 snRNA + Visium」，实际完全不符

| 项目 | 方案描述 | GEO 官方元数据实名 |
| ---- | ---- | ---- |
| 标题 | 11 例乳腺癌 snRNA + Visium | *Spatial Transcriptomics reveals that cells that experience intratumoral hypoxia retain hypoxia-associated transcriptional programs...* |
| 物种 | 人 | **小鼠移植瘤模型（MDA-MB-231 异种移植）** |
| 数据类型 | snRNA + Visium | **仅 Visium，无 snRNA** |
| 样本量 | 11 | **2** |

> **判定：编号错误。样本仅 2 个且为小鼠模型，无法用作「神经-肿瘤-基质直接互作验证」或解卷积参考。**

---

### ⚠️ GSE325196 —— 部分正确，但「配对原发灶」不成立

| 项目 | 方案描述 | GEO 官方元数据实名 |
| ---- | ---- | ---- |
| 标题 | 8 例 BCBM + 8 例**配对原发灶** Visium | *Single Nuclei and Spatial Transcriptomic Datasets in Brain Metastases* |
| 样本结构 | 8 + 8 Visium | **23 snRNA / 12 Visium / 4 Xenium，合计 35** |
| 配对原发灶 | 有 | **无** — 官方描述明确：6 个 Visium 来自冰冻脑转移灶，另 6 个来自 FFPE 脑转移灶，**全部为转移灶** |

> **判定：可用于 Step5 的转移灶保守性验证，但不能做「原发灶 vs 转移灶配对对比」。**
> **方案 Step5「梯度程序保守性对比原发灶」这一对比设计，在该数据集上不成立，需改写为「转移灶间梯度程序异质性」或更换队列。**

> **判定：方案描述准确，用于 Step4 独立临床验证队列。**

### ❓ FUSCC-TNBC Visium 31 例（GSA: HRA015776）—— 网络不可达，且存在版本矛盾

- `https://ngdc.cncb.ac.cn` 连接被远端关闭（RemoteDisconnected），**当前环境下无法下载**。
- 方案同时又提到「FUSCC TNBC mIF 数据集（配套已发表 **Cell 2026**）」。而本次核实发现：
  - 方案中自称 31 例的空间队列与公开编号不匹配；
  - 公开的 TNBC Visium 队列另有其人（见下）。
- 这是**主发现队列**，缺失将导致 Step1–Step3 全部无法执行。

---

GEO / E-utilities 均未检索到对应编号（`FUSCC` 关键词在 `db=gds` 检索返回空）。该队列通常以数据使用申请形式获取。

## 二、检索到的真实可用替代队列（比原方案更强）

在核实过程中，用 E-utilities 做了主题检索，找到以下**元数据已验证**的真实队列：

| 数据集 | 样本 | 平台 | 内容 | 对本项目的价值 |
| ---- | ---- | ---- | ---- | ---- |
| **GSE210616** | **43 例** | GPL24676 | *Spatial transcriptomics of triple negative breast cancer*（人源 TNBC Visium，含 EA/AA 种族差异分层） | **可作 TNBC 空间主队列替代**；43 例 > 原方案 31 例 |
| **GSE322943** | **100 例 Visium**（总队列 156 例 BCBM） | GPL24676 | *Dissecting the cellular architecture of breast cancer brain metastases reveals prognostically distinct immune landscapes*（含 bulk + snRNA + 空间 + 流式） | **BCBM 队列的最优选择**；100 例 Visium 远超 GSE325196 的 12 例，且含**同队列 snRNA**，可直接支撑解卷积而不必外借参考 |
| GSE325196 | 35 例 | GPL24676 | Duke 脑转移 sn+Visium+Xenium | 作为 GSE322943 的**独立重复验证队列** |
| GSE281492 | 101 例 | 多平台 | *Molecular characterisation of the metastatic cell state in Breast Cancer* | 潜在转移状态对照 |

> **关键增益：GSE322943 自带 156 例 BCBM 的 bulk/snRNA/空间配对，意味着跨分子亚型验证与解卷积参考可在同一队列内闭环，比原方案"外借 snRNA 做参考"的设计更严谨。**

## 四、建议的行动方案

由用户提供 FUSCC-TNBC h5ad/SpaceRanger 输出与 mIF 数据文件（本地或网盘授权链接），则 Step1–Step3 按原方案执行，产出即为原创首发队列。

**无论选 A 还是 B**：Step4 的 bulk 临床验证部分（METABRIC + GSE12276）都可先行完成，不阻塞。
