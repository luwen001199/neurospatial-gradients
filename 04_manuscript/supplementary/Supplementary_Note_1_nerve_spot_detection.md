# Supplementary Note 1 — Nerve-associated spot detection: threshold sensitivity

**Question.** The primary nerve-call rule (≥2 markers of the same neuronal class above the 90th sample-level percentile, plus a spatial-cluster constraint) involves two arbitrary constants. This note establishes which downstream quantities depend on them and which do not.

**Design.** A 3 × 2 grid (percentile q ∈ {0.85, 0.90, 0.95} × minimum same-class markers ∈ {2, 3}), each run with and without the spatial-cluster constraint — 12 configurations in total, all 43 samples. For every configuration we recorded (i) the called fraction of spots, (ii) Cohen's *d* and AUC of the composite nerve score in called versus non-called spots, (iii) the same two statistics against an **independent** axon/neuronal marker set never used for calling (*SNAP25, SYT1, NEFH, PRPH, GFRA1, NTRK1, RET, TAC1, ADCYAP1, GAP43, STMN2, SCG2, VGF, CHGB, SLC17A6, RTN1, CHRNA7, KIF5A*), and (iv) the refitted nerve-signal decay length.

Source table: `TableS15_nerve_threshold_sensitivity.csv`. Figure: Supplementary Figure S1.

**Results.** The called fraction spans more than an order of magnitude across configurations — from 0.000% (q = 0.95, ≥3 markers, with spatial constraint, which calls no spot at all in the median sample) to 12.0% (q = 0.85, ≥2 markers, no spatial constraint). Removing the spatial constraint multiplies the called fraction by 2–9× depending on the configuration. Against the composite nerve score, the discrimination is large in every configuration that calls any spot (median Cohen's *d* 1.27–2.53, median AUC 0.854–0.938), so the *internal coherence* of the definition is not threshold-dependent.

The independent-marker readout behaves very differently: median Cohen's *d* against the independent axon/neuronal panel is −0.01–0.15 and median AUC 0.42–0.55 across configurations. At the primary configuration the independent AUC is 0.530. A nerve call that were anatomically correct should elevate independent axonal markers; it does not, and the magnitude of the failure is stable across the whole grid.

The refitted nerve-signal decay length is strongly threshold-dependent: median 1/*b* ranges from 52 µm (q = 0.90, ≥2 markers, no constraint) to 1,162 µm (q = 0.90, ≥3 markers, with constraint). At the primary configuration (q = 0.90, ≥2 markers, with constraint) the median decay length is 147 µm.

**Interim-cohort comparison (30 → 43 samples).** The primary analysis was first run on the 30 samples available at the time and repeated in full on all 43. Every qualitative conclusion was unchanged: the nerve-call yield, effect sizes and the three-line characterisation agree in direction and ranking. Two quantitative differences are quoted in the main text: (i) the interim gene-level program (nominal *P* < 0.05, |ρ| ≥ 0.05) contained 88 genes, of which pruning to the 43-sample cohort leaves 58 — the interim version was diluted by weakly expressed housekeeping members whose aggregate effect flattened the ring profile (Figure 2D); and (ii) calibrated gradient effect sizes shrink systematically with cohort size (e.g. perineural-stroma module −0.109 → −0.070, SPARC −0.083 → −0.052, LRRC15 −0.056 → −0.030), because the random baselines sharpen as *n* grows. Full-cohort values are used throughout the manuscript (Limitation 8).

**Interpretation.** Two conclusions, and they point in opposite directions. The *existence* of a monotone perineural gradient is threshold-robust: every configuration that calls any spot produces a large, consistent near-versus-far difference in the composite nerve score. The *characteristic length* of that gradient is **not** a threshold-independent quantity, and the ~147 µm value quoted in the main text should be read as the value at the pre-specified primary configuration (q = 0.90, ≥2 markers, with spatial constraint), not as a physical constant of the tissue. We therefore use the primary configuration consistently for all primary results and report in the main text that the length scale, unlike the gradient's existence, is threshold-sensitive.
